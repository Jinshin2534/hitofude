# 一筆書き判定 (hitofude)

図形を描くと、一筆で書けるかをオイラー路で判定し、書き順をアニメーションで見せます。
書けない図形には「線をあと何本足せば書けるか」と、足す線の一例を示します。

- 公開: https://hitofude-hantei.vercel.app (`hitofude.vercel.app` は他人のサイトなので別名)
- ブラウザ内で完結(サーバ不要)。手描き入力のみ(写真からの読み取りはしません)

## しくみ

1. **手描き → 点と線**(`src/lib/graph.js`): 線の端・交点・T字(端が別の線に触れた所)を点の候補にし、
   snap 半径(画面上 14px 以上)以内の候補をまとめて点にする。点と点のあいだが線(辺)。輪・多重辺も扱う。
   あと少しで届いていない端は「つながっていないかも」と黄色で示す(判定はつながっていない前提)。
2. **判定**(`src/lib/euler.js`): 奇数の点が 0 個なら一周、2 個なら片方から始めて片方で終わる。それ以外か、図形が離れていれば書けない。
3. **書き順**: Hierholzer 法でオイラー路を求める。
4. **足す線の最少本数**: かたまりごとに max(1, 奇数の点/2) を足した「最少筆数」から 1 を引いた数。
   提案する線は実際に足すと書けることをテストで確認し、本数が全探索の最少と一致することも確かめている。

## 開発

```sh
pnpm install
pnpm dev      # http://localhost:5960
pnpm test     # Vitest
pnpm build
```

`window.__app` からヘッドレスで操作できます(`loadPreset('konigsberg')`, `addStroke(points)`, `summary()`, `play(withFix)`, `seek(0..1)` など)。
